# Nike Project

**English** · [فارسی](#فارسی)

A responsive Nike-inspired shoe storefront landing page built with React, Tailwind CSS, and Vite. The project highlights product presentation, bold typography, responsive layouts, and interactive product image selection.

## Features

- Hero section with featured shoe and collection thumbnails
- Switch the main shoe image from the thumbnail cards
- Popular products grid
- Product services and benefits section
- Quality-focused promotional section
- Customer reviews
- Special offer and newsletter sections
- Responsive navigation and footer
- GitHub Pages deployment configuration

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- PostCSS
- JavaScript (JSX)

## Getting Started

~~~bash
git clone https://github.com/MatinMuhammadi1381/Nike_project.git
cd Nike_project
npm ci
npm run dev
~~~

Open the local URL shown by Vite, usually http://localhost:5173.

On Windows, `INSTALL-DEPENDENCIES.bat` performs the same clean install using `package-lock.json`.

## Available Scripts

~~~bash
npm run dev       # Start the development server
npm run build     # Create a production build
npm run preview   # Preview the production build
npm run lint      # Run ESLint
npm run deploy    # Build and publish to GitHub Pages
~~~

## Project Structure

~~~text
src/
├── components/   # Buttons, cards, navigation, and shared UI
├── sections/     # Hero, products, services, reviews, and offers
├── assets/       # Shoe images, logos, icons, and illustrations
├── constants/    # Product and statistics data
├── App.jsx       # Main page composition
└── main.jsx      # Application entry point
~~~

## Scope

This is a front-end storefront showcase. It does not include a shopping cart, checkout flow, inventory service, or payment integration.
